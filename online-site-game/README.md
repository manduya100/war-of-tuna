# 🌊 바다 온라인 게임 (Ocean Online Game)

실시간 멀티플레이 로비 및 대기실 시스템입니다.

## 🚀 실행 방법

### 방법 1 (가장 간편)
- 바탕화면 폴더의 `온라인_게임_실행.bat` 더블 클릭!
- 자동으로 웹 브라우저(`http://localhost:5000`)가 열립니다.

### 방법 2 (직접 명령어로 실행)
```bash
cd online-site-game
python app.py
```
브라우저 주소: `http://localhost:5000`

---

## 🎮 주요 기능

### 1. 메인 화면
- **좌측 상단 이름 및 아바타 설정**:
  - 내 닉네임을 원하는 대로 설정 (로컬 스토리지에 자동 저장되어 유지).
  - 귀여운 해양 생물 아바타(🐬, 🐢, 🐙 등) 선택 가능.
- **방 만들기**:
  - 버튼 클릭 시 **무작위 10자리 숫자 코드** 자동 발급.
  - 생성자가 대기실의 방장이 됩니다.
- **방 찾기**:
  - 전달받은 10자리 숫자 코드를 입력하여 방 입장.
  - 숫자 10자리 필터링 및 유효성 검사.
- **배경**:
  - 청량하고 푸른 에메랄드빛 열대 바다 배경 (`static/images/ocean_main.jpg`).

### 2. 대기실 화면
- **대기실 코드**: 10자리 숫자 대기실 코드 상단 표시 및 원클릭 복사 버튼.
- **참가자 목록**:
  - 각 참가자 카드(아바타, 닉네임, 방장 표시, 내 표시).
  - **준비완료** / **준비중** 상태 실시간 동기화.
- **방장(Host) 전용 기능**:
  - **강퇴**: 참가자 카드 우측 상단의 `[🚨 강퇴]` 버튼으로 특정 유저 퇴출 가능.
  - **플레이 인원 설정**: 최대 플레이 인원(2~8명) 변경 드롭다운.
  - **플레이 버튼**: 모든 유저가 준비완료 시 게임 시작 버튼 활성화!
- **일반 참가자 기능**:
  - `[준비완료]` / `[준비중]` 토글 버튼.
- **실시간 채팅**:
  - 대기실 유저 간 실시간 채팅 및 입장/퇴장/인원변경 알림 메시지.
- **배경**:
  - 메인 화면과 구별되는 신비롭고 웅장한 깊은 바다 물결 배경 (`static/images/ocean_room.jpg`).

## 🛠️ 기술 스택
- **Backend**: Python 3, Flask, Flask-SocketIO (WebSocket 실시간 통신)
- **Frontend**: HTML5, Modern CSS3 (Glassmorphism, Neon Theme), JavaScript (ES6+), Web Audio API
